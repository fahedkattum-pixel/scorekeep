# Pool ScoreKeep Web

This is a no-build PWA version of the scorekeeper. It keeps the native SwiftUI project intact and stores match history in the browser with `localStorage`.

## Run locally

From this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

On iPhone, serve it from a reachable computer address, open it in Safari, then use **Share > Add to Home Screen**.
